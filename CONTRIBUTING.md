# Contributing / 贡献

Use fake accounts, temporary directories and mock network responses. Never include real Cursor tokens, cookies, emails or database content. Run `npm test`, `npm run build`, Rust fmt/test/clippy, and describe user-visible changes in the PR. By contributing, you agree that your contribution is licensed under MIT.

请只使用假账号、临时目录和 mock 网络；禁止提交真实 Token、Cookie、邮箱或数据库内容。提交 PR 前运行前后端测试与构建。
